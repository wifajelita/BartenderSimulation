# Bartender Simulation 🍸

**Play now:** [https://bartendersim.my.id/](https://bartendersim.my.id/)

Game simulasi bartender berbasis web dengan tema **Maroon & Beige**. Buat cocktail klasik sesuai pesanan pelanggan, kumpulkan tip, dan naik level!

## Cara Main
1. Buka [bartendersim.my.id](https://bartendersim.my.id/) di browser (Chrome / Firefox / Edge recommended)
2. Pilih mode **Solo** atau **2 Player (Lokal)**
3. Klik **Mulai Bekerja**
4. Baca pesanan pelanggan → pilih bahan (lihat Buku Resep)
5. **Kocok** atau **Aduk** sesuai resep
6. **Sajikan** sebelum kesabaran pelanggan habis
7. Kumpulkan uang & skor

## Fitur
- 🔊 **Sound Effect** (pour, kocok, aduk, sukses, gagal, dll) — Web Audio API
- 🎵 **Backsound ambient** tenang ala bar/lounge — bisa di-toggle
- 👥 **Multiplayer lokal (Versus)** — 2 pemain bergiliran, skor terpisah
- Mute button & BGM on/off di header
- 8 resep cocktail klasik
- 16 bahan
- Sistem kesabaran pelanggan + timer per hari
- Kesulitan naik tiap hari
- Fully responsive
- Animasi fluid

## Kontrol Audio
- 🔊 = Mute / Unmute semua suara
- 🎵 = On / Off backsound saja
